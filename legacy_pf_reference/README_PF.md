# 📦 Inventory Management System (IMS)

A professional console-based **Inventory Management System (IMS)** developed in **C++** as a **Programming Fundamentals Semester Project**.

The system allows administrators to efficiently manage products, inventory, stock movement, reports, and data storage using file handling.

---

## 📖 Project Overview

This project demonstrates the practical implementation of core Programming Fundamentals concepts including:

- Functions
- Arrays
- Strings
- File Handling
- Conditional Statements
- Loops
- Searching
- Sorting
- Menu Driven Programming
- Data Validation

The system provides an easy-to-use console interface for managing inventory records.

# 💻 How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/inventory-management-system.git
```

2. Open the project in VS Code.

3. Compile

```bash
g++ main.cpp -o inventory
```

4. Run

```bash
inventory.exe
```
